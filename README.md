# Interpretable-Fake-News-Detection-Frontend-sem-7-project-
It’s a system that reads a news article and classifies it as real or fake. It compares a classical machine learning model, like Logistic Regression on TF-IDF features, against a fine-tuned BERT model. The special part is the explainability: it uses LIME and SHAP to highlight which words pushed the prediction toward fake or real.
